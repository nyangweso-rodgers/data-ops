# Setup

- Remarks:
  - We can use **SQLite** as the backend store for **MLflow** without running it in Docker or using Docker Compose. **MLflow** supports **SQLite** as a lightweight database for storing experiment metadata (e.g., **runs**, **parameters**, **metrics**) and can be set up directly on your local machine or any environment where **MLflow** is installed.
